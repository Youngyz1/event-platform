# ALDRIVA Logo System

This folder contains a vector-first brand identity exploration for ALDRIVA.

Files:

- `presentation.html` - full brand presentation board with four distinct concepts, color directions, lockups, app/avatar and favicon applications.
- `svg/aldriva-concept-01-convergence-gate.svg` - primary logo export.
- `svg/aldriva-concept-02-modular-lattice.svg` - primary logo export.
- `svg/aldriva-concept-03-portal-horizon.svg` - primary logo export.
- `svg/aldriva-concept-04-prism-ribbon.svg` - primary logo export.
- `svg/aldriva-wordmark-mask.svg` - custom vector wordmark silhouette used by the presentation.

Open `presentation.html` directly in a browser to review the system.
